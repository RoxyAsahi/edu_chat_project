      模型用途

      思考模式强度控制“思考”聊天的推理预算。低强度会更快开始输出，默认则交给模型服务。

      来源检索

      Rerank 重排用重排模型重新排序候选片段，提高命中质量。
      返回片段数最终注入对话的来源片段数量。
      候选片段数重排前先取多少条候选，数字越大越慢。
      最低相关度低于这个分数的来源片段会被过滤。
      学生姓名用于 {{StudentName}}。
      所在城市用于 {{City}}。
      年级用于 {{Grade}}，帮助调整讲解难度和表达方式。

      气泡提示词

      气泡渲染提示词这是全局最重要的一段提示词，用来约束 AI 生成可直接渲染的网页式回答气泡。
      建议把主要的 HTML/CSS 渲染风格约束集中写在这里。
      表情包提示告诉模型可用表情包和图片伪路径，通常无需对外展示。
      启用学习日志允许 AI 在合适的时候写入 DailyNote，作为长期学习记忆。

      协议文本

      DailyNote 协议文本定义写入学习日志时使用的协议格式，留空时使用内置默认协议。
      追问提示词模板用于回复完成后生成后续追问。
      自动命名话题首轮助手回复成功后尝试自动生成话题标题。

      UniStudy

      个人 AI 学习空间

      UniStudy 面向多学科学习场景，将资料导入、主题对话、笔记沉淀、复习训练和学习记录连接成一个连续流程，让 AI 真正参与学习过程。

      flag 项目用途

      用于日常学习、专题整理、考前复习和资料管理，也作为参加第五届上海市青少年人工智能与编程实践活动的作品，展示 AI 在真实学习场景中的辅助价值。

      person 开发者

      杨晨晢独立开发。

      terminal 开发协作

      开发过程中借助 Codex 与 Claude Code 进行实现、调试和整理。

      auto_awesome 核心能力

      资料书架、话题来源、聊天收藏、Notes、选择题、闪卡、学习日志和可渲染的 HTML 回答气泡。

      psychology 具体模型

      GPT-5.5、Claude Sonnet 4.6、gemini-3.1-pro、kimi k2.6。

      hub 作品定位

      不是单次问答工具，而是把看资料、提问题、记重点、做练习、再复习串起来的桌面端学习工作台。
