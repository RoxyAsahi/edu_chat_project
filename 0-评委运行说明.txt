UniStudy 评委运行说明

推荐方式：
1. 双击根目录下的 1-先运行-UniStudy安装包.exe。
2. 按安装向导完成安装。
3. 安装完成后，从桌面快捷方式或开始菜单启动 UniStudy。

说明：
- 安装包已包含 Electron 运行环境。
- 评测电脑不需要额外安装 Node.js、npm 或 VS Code。
- 首次使用 AI 对话、资料检索等联网能力时，需要在 Settings 中配置模型服务地址、API Key 和默认模型。

备用方式：
- 如果评测电脑不便安装，可打开 2-免安装备用-UniStudy 文件夹，双击其中的 UniStudy.exe。
- 不要把 2-免安装备用-UniStudy 文件夹里的 UniStudy.exe 单独移出文件夹，它依赖同目录下的 resources、locales、dll、UniStudySeedData，以及 UniStudyData/.unistudy-portable 标记文件。
- 免安装备用版的运行数据会保存在 2-免安装备用-UniStudy\UniStudyData，不会写入 Program Files。
- 如果根目录里还看到 UniStudy-contest 文件夹，那是调试旧目录，请不要提交、不要运行。

源程序复现：
- 如需从源代码运行，请安装 Node.js v22.17.1 或兼容版本。
- 在项目根目录执行 npm install，然后执行 npm start。
